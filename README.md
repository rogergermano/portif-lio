Bem-vindo ao repositório do meu portfólio profissional! Este projeto reúne casos práticos de impacto financeiro, automação de processos e engenharia de dados aplicados à resolução de gargalos operacionais e de vendas.

## 🚀 Sobre Mim

Atuo na interseção entre **Engenharia de Dados (Analytics)** e **Estratégia de Negócios**. Unindo bagagem em Gestão Comercial e Controladoria ao desenvolvimento técnico, meu foco é transformar dados brutos de sistemas ERP em pipelines automatizados, modelos preditivos e painéis de tomada de decisão que aumentam faturamento e reduzem custos operacionais.

## 📌 Projetos em Destaque

### 1. Pipeline de Inteligência Comercial End-to-End
* **Tecnologias:** SQL Server, Python, Google BigQuery, Looker Studio.
* **Descrição:** Pipeline ELT para extração de dados brutos do ERP, limpeza, modelagem estatística (RFM, Z-Score, Cross-Sell) e disponibilização de dashboards interativos para a diretoria.

### 2. Diagnóstico de Estoque Parado & DTE (Single Page App)
* **Tecnologias:** Apps Script, BigQuery, HTML/CSS.
* **Descrição:** Web App para identificação em tempo real de capital imobilizado em estoque, aplicando réguas de Dias de Cobertura (DTE) para tomada de ação rápida na liberação de caixa.

### 3. Automação de CRM, WhatsApp & Auditoria de Dados
* **Tecnologias:** n8n, Node.js, WhatsApp API, Python, SQL.
* **Descrição:** Fluxo automatizado de recuperação de orçamentos não convertidos, integrado a scripts de auditoria em SQL para saneamento de cadastros de clientes e produtos.

### 4. Sistema de Endereçamento Logístico WMS
* **Tecnologias:** Python, ERP Sync, Mobile Interface.
* **Descrição:** Módulo customizado de endereçamento físico de estoque (Rua/Coluna/Gaveta) integrado ao ERP para otimização de picking e organização de depósito.

### 5. Relatórios Executivos Automatizados via IA
* **Tecnologias:** Gemini API, Python, BigQuery.
* **Descrição:** Integração com LLMs para interpretação automática de métricas semanais e geração de resumos estratégicos para os gestores.
