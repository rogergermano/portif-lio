Consulta de Estoque e Preços em Tempo Real (FastAPI)

Aplicação Web/REST API on-premise para consulta instantânea de estoque físico e preços via celular no salão de vendas, eliminando a dependência de terminais ERP tradicionais.

  • API Assíncrona: Backend em FastAPI + pyodbc com queries parametrizadas (código, descrição, estrutura mercadológica, saldo mínimo) e autenticação via Bearer Token.
  • UX Mobile-First: Frontend em JavaScript puro, ordenação dinâmica de tabelas por estoque/preço e suporte a PWA/atalho de tela inicial.
  • Infra Zero-Touch: Deploy on-premise em Windows Server com inicialização automática via Task Scheduler e segredos isolados em .env.
